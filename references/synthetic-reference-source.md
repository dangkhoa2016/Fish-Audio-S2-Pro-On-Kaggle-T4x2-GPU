# Synthetic Reference Source

The reproducible synthetic speaker bank used by the final voice-cloning acceptance is generated with OpenBMB VoxCPM2.

- Upstream model: `openbmb/VoxCPM2`
- Resolved upstream commit: `32279effe8c19989596f05d353d1447f51d9e915`
- Kaggle mirror: `dangkhoa2016/openbmb-voxcpm2`
- Python package: `voxcpm==2.0.3`
- Mirror license metadata: Apache-2.0
- Mirror provenance: `_kaggle_mirror_provenance.json` in the attached Kaggle model

VoxCPM2 model weights are not committed to this repository.

The canonical generated references are retained under `results/synthetic-speaker-bank/`. They are synthetic model-generated voices and are not recordings of real people.
