# Model source

- Original source: `https://huggingface.co/fishaudio/s2-pro`
- Kaggle mirror used for this project: `dangkhoa2016/fishaudio-s2-pro`
- Mirror policy: weights must remain unchanged from the upstream model.
- Runtime notebooks should prefer the attached Kaggle Model path to avoid downloading weights during GPU sessions.

The exact Kaggle mount path is discovered at runtime because Kaggle may vary the directory layout by model/version attachment.
